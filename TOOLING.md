# Tooling

The tool registry is [GOVERNANCE.md](GOVERNANCE.md).
work_leases/check_work_leases.py validates operational coordination records.
It does not certify mathematics or establish CBZ-0. Python 3.11 or newer is
required; there are no third-party dependencies.

Exact verification commands are in [STATUS.md](STATUS.md#how-to-verify).
All original fixture tests remain in work_leases; the added regressions are
work_leases/test_check_work_leases_validation.py.
